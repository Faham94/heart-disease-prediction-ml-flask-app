# ❤️ Heart Disease Prediction Web App

This is a full-stack Machine Learning project built using Flask.

## 🚀 Features
- Interactive UI for prediction
- Multiple ML models used
- Best model: SVM
- Real-time predictions

## 🧠 Models Used
- Logistic Regression
- KNN
- Naive Bayes
- Decision Tree
- SVM

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas, NumPy

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app.py

Then open:
http://127.0.0.1:5000/
